### 介绍
矩形材质包-建筑（Matrix Sprite Building Texture Pack）是一款针对于《Mindustry》的视觉优化材质包，专注于修改 **建筑(block)、特效(effect)与用户界面(ui)** 的贴图。

### 风格
本材质包对原版的结构与花纹进行了适当简化与矩形化，并将许多的斜线与曲线设计修改为了矩形组合图形。
而为保证视觉风格统一，本材质包将 **如电力节点（power-node）等塞普罗科技树** 及 **绝大多数的埃里克尔科技树** 下的多边形结构建筑也修改为了正方形结构。
除此之外本材质包还覆盖了 **建造栏和建造虚影中的建筑贴图（-ui与-full）** 和 **部分用户界面与特效** ，以确保视觉风格统一。

### 亮点
本材质包别出心裁地将传送带动画替换成了 **静止的箭头样式** ，这使得玩家即使是在暂停的情况下也能够快速、准确地判断出其运输方向。

### 其他
本材质包是在业余时间制作的，所以更新会比较缓慢。
